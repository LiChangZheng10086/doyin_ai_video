# 科技博主文案改写

将技术文案转换为科技博主的口播风格——专业、有感染力、像在跟观众面对面聊天。

## 用法

```
!tech-blogger-narration <文件路径或直接粘贴文案>
```

## 改写原则

### 1. 开场要有"钩子"
不要平铺直叙，用问句、惊人事实、或反常识观点开头。

```
❌ "Transformer是一种基于自注意力机制的神经网络架构。"
✅ "你知道今天所有大模型能读懂你的话，全靠一个叫Transformer的架构吗？"
```

### 2. 用"你"拉近距离
全程面向观众说话，让对方感觉你在跟他一对一交流。

```
❌ "该模型通过多层神经网络提取特征。"
✅ "相当于你给模型看了几亿个例子，它自己就学会了怎么提取特征。"
```

### 3. 复杂概念要"翻译"
技术术语保留，但用类比/比喻解释。

```
❌ "自注意力机制通过计算QKV矩阵的相似度来捕捉长距离依赖。"
✅ "自注意力的核心思想特别简单：每个词都去"关注"句子里的其他词，看看谁跟自己关系最密切。就像你在人群中找人，你的注意力会自动锁定那个最显眼的目标。"
```

### 4. 保留原文所有技术细节
不删除任何技术信息（模型名、数据指标、代码、架构名），只改进表达方式。

### 5. 删除口语废词
去掉"嗯、啊、呃、那个、这个、就是说"等废词，保留流畅的口语节奏。

### 6. 段落要有节奏
长短句交替，适当停顿。不要全是长难句。

### 7. 收尾要有"行动号召"或"总结金句"

```
✅ "所以下次你用ChatGPT的时候，背后就是这套机制在运转。理解了这个，你就懂了AI为什么突然这么强。"
```

## 风格参考

科技博主语调特征：
- 语速偏快，信息密度高
- 偶尔用"惊了"、"离谱"、"绝了"等感叹词（节制使用）
- 技术自信，不模棱两可
- 有个人观点和判断，不只是复述事实
- 适当用数字和列举增加可信度

## 输出格式

直接输出改写后的完整文案，不要额外说明。
