## 测试场景 1：无 API Key 时的行为

### 预期行为
1. ✅ 顶部导航栏显示 "⚠️ 未配置 AI" + "前往设置" 链接
2. ✅ 点击"创建任务"按钮，弹出警告对话框
3. ✅ 警告对话框内容正确："您还没有添加 AI API 密钥..."
4. ✅ 点击"前往设置"按钮，跳转到设置页面
5. ✅ 点击"取消"按钮，关闭对话框

### 测试步骤
- [ ] 打开应用，观察顶部状态指示器
- [ ] 点击"创建任务"按钮
- [ ] 验证警告对话框显示
- [ ] 点击"前往设置"测试跳转
- [ ] 返回任务列表，再次点击"创建任务"
- [ ] 点击"取消"测试关闭

## 测试场景 3：智能轮询

### 预期行为
1. ✅ 没有任务时，不轮询（右下角无"轮询中..."提示）
2. ✅ 创建任务后，开始轮询（右下角显示"轮询中..."）
3. ✅ 任务处理中时，3 秒刷新一次
4. ✅ 任务完成后，15 秒刷新一次
5. ✅ 删除所有任务后，停止轮询

### 测试步骤
- [ ] 观察空任务列表，确认无轮询
- [ ] 创建一个任务
- [ ] 观察右下角轮询指示器出现
- [ ] 观察任务状态自动更新（从 queued → processing → done）
- [ ] 任务完成后，观察轮询频率降低（15秒）
- [ ] 切换到设置页，确认轮询停止
- [ ] 返回任务列表，确认轮询恢复
