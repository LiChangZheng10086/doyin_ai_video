# 热点模块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在桌面项目内浏览最新可获取的综合热榜、辨别缓存和错误、收藏选题并保存备注。

**Architecture:** 固定来源 HTTP 获取 → 有界运行时解析 → 每源 JSON 缓存 → Express 路由 → React 热点页。收藏独立索引，复用本机会话、原子写入与现有设计令牌。

**Tech Stack:** Node fetch、Express、TypeScript、React、LocalStorage；零新增依赖。

**Spec:** `docs/superpowers/specs/2026-09-30-hotspots-design.md`

## Global Constraints

- 默认 10 分钟缓存，手动刷新最短间隔 60 秒；每源最多 100 条。
- 每请求 8 秒超时、响应最多 1 MiB，固定来源 URL，禁止跟随重定向。
- 备注最多 2000 字符；更新必须带版本，冲突 409。
- 不读取用户平台登录态，不自动创建作品、不生成或发布，不新增依赖，不提交/推送现有脏工作区。

## Review Focus

- 上游成功状态但返回空串或挑战页：不得清空旧有效榜单。
- 同源并发刷新、收藏并发操作：不得重复抓取或丢失收藏。
- 失效/恶意链接、客户端自造条目：不进入可点击榜单或收藏。
- 缓存损坏/远程失败：各源独立降级且不得冒充最新。
- 保存备注失败或旧版本冲突：弹窗保留未保存文本。
