# 原视频字幕条拼接排版

用户给定参考图确认本次视觉目标：满宽主画面，下方连续排列原视频字幕条；每条保留对应时间的画面背景与原生字幕，不能仅显示孤立文字和大块黑色间隔。

沿用本地 FFmpeg、1080×1440、6～9 条均衡规划与整套人工确认。新增内部 `filmstrip` 排版标记，仅新自动方案启用；旧 `compact` 和手动配置保持原行为，保存时保留标记。主画面按取景区域满宽缩放并居中裁切；字幕条以同一时刻的取景画面为背景，中央拼入该时刻完整原生字幕像素带，上下至少各 20 输出像素画面。直接衔接，不重绘或修正文案，不伪造原视频背景。

每条高度至少 96，且不小于原生字幕带缩放后的高度加 40；主画面至少 432。规划容量与渲染使用同一高度规则，字幕过高时增加图片，不压缩字幕字形。主画面高度尽量按 `mainFraction` 分配，其余空间被字幕条完整使用。满宽取景可能裁掉上下内容，可通过已有高级调整修改取景。

验收：两种真实 FFmpeg 背景按时间分别出现在字幕条上下；白色原生字形保持完整且每条只出现一次；主画面左右无人为黑边；输出固定尺寸；旧配置照常渲染；类型校验、草稿保存、自动规划标记和预览/最终哈希一致。测试通过后重编译并重启，以同一真实图集重新规划候选，不自动确认、生成正式成品或发布。

规格自审：只改变排版，不改变字幕识别与源安全检查；参考图片只用作视觉要求，不成为素材；无新依赖、无布局选择器和发布动作。
