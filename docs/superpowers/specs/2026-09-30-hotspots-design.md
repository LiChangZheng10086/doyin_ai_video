# 热点选题模块

用户于 2026-09-30 认可前轮方案并明确要求直接开发。综合热点优先，独立 `/hotspots` 主导航，作为创作前的选题入口，不自动建视频任务、生成内容或发布。

## 范围与架构

- 现有 Express 后端直接获取固定来源，React 使用既有 apiClient；复用 LocalStorage 原子 JSON 写入，不新增依赖、数据库、MCP 或独立服务。
- 首版上线实测有效的抖音、知乎、B站、百度、今日头条。微博本机公开接口 403，暂不上线；不借用用户 Cookie，不使用固定 Cookie。抖音仅获取本次请求的匿名 Cookie，不持久化。
- 来源接口和结构参考 MIT NewsNow，保留第三方版权和许可。不开启 X、小红书采集、财经行情或投研。

## 数据与刷新

- 条目含 sourceId、itemId、title、url、rank，可选原始 heat/summary；各平台热度不混算，榜单获取时间不冒充事件发布时间。
- 每源最多 100 条，固定远程 URL，每请求 8 秒超时、响应最多 1 MiB，禁止跟随重定向；运行时检查结构、标题、来源链接、去重、保留原榜序。
- 成功结果缓存在 `cache/hotspots/{sourceId}.json`。默认 10 分钟缓存，手动刷新最短间隔 60 秒；并发同源请求合并，失败也限频。
- 各源独立失败，旧有效数据保留并标记过期；无旧数据标为不可用。空响应、挑战页、空榜单不得报成功。缓存损坏不覆盖收藏。
- 服务端返回缓存到期时间，页面停留时每 30 秒校正过期标签，不发后台请求；文件协议使用 Hash 数据路由，开发 HTTP 保持普通路径。

## 收藏

- `cache/hotspot-favorites.json` 保存来源条目快照、备注、版本与时间。收藏只能引用服务端已有榜单条目，不能客户端注入标题或 URL。
- 重复收藏幂等；备注最多 2000 字符，更新带版本，过期编辑 409；串行原子落盘避免并发丢失。取消收藏仅删除该收藏，不修改创作或发布数据。
- 收藏保留原始获取时间，即使条目下榜仍可浏览和备注。UI 提供来源筛选、标题搜索、原文链接、手动刷新、收藏页签和明确的保存动作。
- 备注弹窗内编辑，未保存时关闭须确认；保存失败保留文本。

## 验收

- 离线夹具覆盖五源解析、异常/空榜/不安全链接、缓存过期/限频/并发、失败降级和收藏持久化/版本冲突。
- HTTP 验证读接口、收藏会话权限和参数校验，既有创作/发布用例不回归。
- 真网络逐源验证，UI 验证收藏、备注、刷新、筛选与窄屏；假数据测试与真实来源测试分开记录。
- 全量 npm test、check、build 与 diff-check。现有未提交公众号/图集改动保持，不自动提交或推送。
