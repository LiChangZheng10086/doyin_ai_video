# 热榜排版与外观主题

用户要求修复热榜留白，确认「深色、浅色、跟随系统」方案，并追加恢复已安装 sau 的配置。

- 热榜采用原生 CSS 多列，卡片不可跨列拆分，列内紧接排列；1/2/3 列断点沿用现有规则。平台顺序按列从上到下阅读，单平台仍是一列，不裁切标题。
- 按用户后续指示，主题入口改为桌面/窄屏右上角常驻原生选择器，移除新建外观分组。主题立即全局生效；复用 index.css 令牌、既有 Zustand 和桌面 app.theme 保存机制，不新增依赖。原生控件 color-scheme 同步；图片标题整个区域用 70% 黑遮罩，蒙版上的字保持浅色。
- 旧 app.theme 字段从未生效：没有 themeConfigured 标记时保持现有深色，用户首次选择后才保存标记。桌面偏好以配置为准，浏览器用 localStorage；读取/保存失败有提示，不覆盖其它配置。
- 跟随系统监听 prefers-color-scheme，手动主题不受系统变化影响。启动在 React 挂载前读取偏好。浅色文字/状态对比度 ≥4.5，交互边界 ≥3。
- sau 仍为外部安装。Electron 按显式环境变量优先、持久化配置回退；两项均未保存时，完整的首次环境路径记入本机配置。已有配置（包括仅填一项）不被临时覆盖或混配。可选路径记忆失败只警告，不阻止当前窗口和后端启动。此次恢复已确认存在的安装，不安装依赖或发布内容。
- 保留脏工作区，不提交/推送，不修改 AI/平台凭据；浏览器验证独立会话，构建后用户窗口无未保存编辑时正常重启。
