# 字幕图集配套文案

用户已认可：完整图文包含整套原生字幕图片、标题、背景引入、按实际内容组织的编号要点、结尾互动及相关话题。

自动规划沿用图集原视频与完整转录，并将已识别字幕作为核对材料。新文案遵循来源事实，不凑固定条数，不编人物、金额、经历或运营者身份与更新承诺。输出受项目抖音图文限额（标题20、正文1000、话题10×20）校验，超长要求重写压缩，不截断末尾；AI至多三次尝试，独立于图片规划。

采用已有运行时 AI 配置，无新依赖。空正文时自动规划同步成文；已有正文保留，提供独立重新生成入口，已有文案替换须在产品界面明确确认。未保存编辑先保存。AI失败不删除文案或图片方案，自动规划仍交付图片并显示文案失败原因；独立生成失败不修改原记录。

只改文案时保留 plan、appliedPlanId、生成图片和原哈希；改图片时沿用方案失效规则。AI文案绑定转录哈希与源指纹，输入变化提示重新生成，发布预览拒绝旧AI文案。文案说明中的事实仍须人工核对；字数由服务端共享政策下发。

验收覆盖完整输入未截断、客观归因提示、平台限额及失败重试，版本/来源变化拒绝，图片预览保留与发布版本失效、失败保留手写内容，页面生成/替换提示及字数展示。最终构建与重启后生成该图集文案供用户核对，不自动发布或推送。

自审：文案整理不等于字幕真实性证明；不以模型自评宣称事实验证成功；不新增来源搜索、付费服务、风格配置器或平台。

真实验收补充：未经核实的任务标题和旧图集标题不送入模型，避免营销标题中的数字被当成来源事实。正文使用面向读者的表达，处理过程与疑点只放在待核对提示中。DeepSeek 调用使用顶层 `thinking: {type: "disabled"}`，输出预算遵从已配置的 maxOutputTokens，缺省2400，截断响应仍拒绝。
