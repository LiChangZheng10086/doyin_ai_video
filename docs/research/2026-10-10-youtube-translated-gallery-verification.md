# YouTube 中文译文图集验收（2026-10-10）

用户认可单条链接方案，并明确中文译文、保留原文核对。本次在隔离工作区实现，未读取默认浏览器 Cookie、未向真实平台发布，模拟测试只写临时存储。

## 真实来源

用户提供 https://www.youtube.com/watch?v=0Z-vhBvBmUY 。元数据标题「对话孙宇晨：年轻人如何抓住AI时代的机会？」、时长 15749 秒（4:22:29）。yt-dlp 在当前客户端响应中未返回人工或自动字幕，不能证明所有地区／客户端都无字幕。

系统2026.03.17及旧打包2026.07.04可读取元数据，但媒体样本下载出现HTTP403；显式web客户端返回登录校验。未登录、未绕过账户限制。最新版官方2026.08.19成功下载请求60秒的片段，关键帧拷贝实际约70秒、3.37MiB，约1分29秒下载。真实 FFprobe：1920×1078 AV1、Opus。项目 MediaService 生成16kHz单声道PCM WAV，内置 whisper.cpp small 多语言 auto 模式识别为zh，约14.287秒完成26分段，实际音频69.9935秒。开头包括「现在呢可能就是也很简单」「我现在就是起床之后呢」。这是短片段验收，未对整段4小时或一小时视频做完整转录，不能据此推断全片性能与准确率。

## 隔离验证

- 字幕：平台路由、人工优先、原语言与非机器翻译轨道、JSON3滚动重复与合法重复、非法时间/文字拒绝、全原文保留、无字幕auto ASR、字幕源标签、主动Cookie契约、长请求超时回归。
- 翻译：严格完整编号覆盖、批次8段/5000原文字符、每批最多3次、截断/缺项/重复/空文/非中文/超长拒绝，失败不覆盖旧译文。原文/时间和来源不可由PATCH修改。
- 图集：译文修改使旧方案和成品有效引用失效；源、转录与版本复核；中文原文对照；长文字减少条数、超35张拒绝；必须逐张确认。外部文本转义、仅嵌入本地PNG，隔离浏览器禁止外部请求与远程字体，实测排版溢出拒绝。
- 真实FFmpeg/Chromium：1080×1440输出、重复渲染字节一致、可读中文字幕。API从合成原视频／原文／译文→预览→确认→成品→自包含发布包完整通过，已建包不随译文修改变化。原生字幕像素模式回归通过。
- `node --import tsx scripts/verify-subtitle-gallery.ts --translated`：32条英文夹具与中文译文→4张预览→生成→重生成文案保留图片→发布预览→重转录拒绝旧依据。真实API与真实图像渲染，AI及转录命令为明确夹具，不证明真实译意准确。

- 全量回归快照：1257通过、1跳过、0失败。审查之后的增补修复分别以媒体9项、原文API3项、图集/API13项针对回归通过；打包缓存另跑2项，包含失败保留旧文件。
- `npm run check` 后端／前端类型检查与凭据扫描通过；三套 `npm run build` 通过（Vite仅现有大chunk提示）。后续修复在完成时再次检查编译。
- 内部独立审查发现并修复默认PATH FFmpeg定位与原文API繁简转换两项问题，当前无剩余P1/P2。译文修改时立即提示旧配套文案需重生成。
