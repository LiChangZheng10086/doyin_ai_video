# 公众号配图绑定与自然写作验收

## 实现

自动文章默认在配图提示词完成后等待用户外部生图，复用现有上传接口保存 generationPrompt 快照，再校验文章版本与当前计划进行绑定。封面和正文图直接进入对应位置，替换保留旧素材；改稿和重规划使旧图失效并保留参考。部分绑定不允许交付，人工选图明确解除本篇位置绑定。公众号独立写作与旧视频成文入口均增加具体动作、条件、自然段落与避免模板化的写作规则，不伪造经历。

## 验证

- 测试先失败后修复：绑定入口缺失、旧图未失效、缺图仍可预览交付、封面数量未校验。
- 文章写作／服务／自动恢复／HTTP 相关定向测试 76 项通过；旧微信成文与自动工作台 55 项通过；导航保护 3 项通过。最后单独复核绑定 HTTP 集合 8 项通过。
- `node scripts/verify-article-auto-research-ui.mjs`：16 组隔离检查通过，Chromium 152。用户外部图片替代文件上传、提示词快照、章节显示、恢复不重写、上传中导航与模式切换保护、未保存描述保护、桌面和390px无溢出均通过；无页面异常、真实模型请求、微信写入或外部网络请求。
- `npm run check` 通过（后续接口调用方 fixture 更新后 renderer 检查另行通过）；`npm run build` 通过，三套产物均更新；`git diff --check` 通过。已有包体大小告警保留。
- 全量 `npm test` 共1391项：1389通过、1跳过、1失败。失败为同时正在修改的 `Microsoft Research reads without the browser UA that triggers 403; other readers retain headers and pinned DNS`，运行时旧实现仍发送 Mozilla/5.0。没有修改该来源功能；当前源码独立复测 article-sources 10项通过。全量运行并非全部绿色，不将定向复测说成完整重跑。
- 独立审查发现并修复：旧图残留、多封面无法完成、部分图片绑定即可交付、上传中导航／继续创作／步骤切换竞争。保留其他聊天的暂存与并行工作，不提交微信。

## 验收边界

本记录对应的隔离检查没有使用真实模型重新生成整篇文章或调用外部生图工具；自动测试不证明新稿文风已达到用户满意，也不证明生成图片质量。旧稿不自动改写，已有微信草稿和自包含包不修改。
