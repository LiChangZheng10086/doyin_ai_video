# 内置油管浏览页验收

## 功能与边界

新增桌面「油管」页（`/youtube`），搜索／粘贴链接、首页、刷新、前进后退与采集当前视频。窄屏从「更多」进入。采集只创建现有手动作品并进入详情；下载、字幕、转录与图集沿用原流程，需要使用者继续操作。

官方网站通过独立 `persist:youtube-browser` 会话的 WebContentsView 打开。无应用 preload、Node 权限，启用 sandbox 与 contextIsolation；只允许固定 HTTPS YouTube／Google 登录同意域名。拒绝网页下载与设备权限，IPC 校验本机应用主 frame。加载／失败／搜索／频道页不能采集，视频 ID 必须完整，归一化链接不携带列表或跟踪参数。离开页、应用重新加载和任何应用模态弹窗均隐藏并静音，返回保留位置。

## 自动化验收

15 项定向回归通过，包含 URL、视频 ID、IPC 来源、导航状态、失败与恢复、区域裁剪、隐藏与销毁、导航入口以及普通浏览器的桌面版提示。

`node scripts/verify-youtube-browser.mjs` 使用实际 Electron、编译 renderer/preload 和临时 Express 存储。仅测试环境通过 CDP 返回明确合成的 HTTPS YouTube 页面，不修改生产准入规则。验证：

- 真正的 WebContentsView、独立会话、无 window.electron／require／preload。
- 搜索、单条视频、SPA Shorts 地址更新与原生前进后退。
- 800×600 区域校准、390×800 无水平溢出、真实「更多」弹窗隐藏与恢复。
- 外部顶层跳转拒绝、刷新恢复。
- 首次 API 503 不失去页面；同步双击只创建一次；实际现有 API 中产生唯一规范化链接的手动作品，所有步骤 pending、无下载文件，跳转作品详情。
- 离开页后原生视图不可见且静音；返回和重新加载仍只有一个视图。

所有浏览 profile 与测试作品存储临时隔离并清理，未创建真实用户测试作品。原生 child view 的截图须通过其自身 webContents.capturePage 取得，主 renderer 截图不包含原生 child 的合成画面。
