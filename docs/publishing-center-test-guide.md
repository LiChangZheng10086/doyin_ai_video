# 发布中心测试文档

## 1. 测试范围

本文件覆盖 `codex/publishing-center-v1` 分支的发布中心、操作者权限、发布包向导、资产校验、发布状态、排期恢复、垃圾桶以及相关 API。

测试版本：`99aeda6`  
测试日期：2026-08-10  
测试环境：macOS，Node.js `v24.14.0`，npm `11.9.0`

## 2. 环境准备

```bash
npm install
npm run build:backend
npm run build:renderer
npm run build:electron
```

启动开发环境：

```bash
npm start
npm run dev:renderer
npm run dev:electron
```

浏览器验收地址通常为 `http://localhost:5173`。桌面端会加载同一个渲染器，并使用随机本地端口启动内嵌后端。

准备两个本地用户：

| 用户 | 权限 | 用途 |
| --- | --- | --- |
| 发布员 | publisher | 验证普通发布权限 |
| 验收管理员 | admin | 验证管理员操作、PIN 和垃圾桶 |

若测试视频资产，需要额外准备有效的 MP4 文件，并确认 `ffmpeg`、`ffprobe` 可执行。若测试真实 HyperFrames，需要 Node.js 22+、FFmpeg 和可用的 HyperFrames CLI。

## 5. API 测试

### 5.1 基础接口

```bash
curl -i http://localhost:3100/health
curl -i http://localhost:3100/api/jobs
```

预期：`/health` 返回 HTTP 200，JSON 中 `ok` 为 `true`；任务接口返回合法 JSON，不泄露 API Key、PIN 或本地绝对路径中的敏感信息。

### 5.2 权限与错误

| 编号 | 验证项 | 预期 |
| --- | --- | --- |
| API-01 | 未携带本地会话调用写接口 | 返回 401 或明确的权限错误 |
| API-02 | 普通发布员调用管理员接口 | 返回 403，不产生副作用 |
| API-03 | 不存在的发布包 ID | 返回 404 和结构化错误消息 |
| API-04 | 重复确认同一发布包 | 返回冲突或幂等成功，不创建重复记录 |
| API-05 | 伪造用户编辑来源字段 | 服务端按请求会话重新计算来源，不信任客户端标记 |
| API-06 | 封面读取接口 | 返回可访问图片或明确的缺失状态，不返回任意文件 |

## 8. 已知限制

- 默认测试不会调用真实抖音下载、AI 中转或 HyperFrames 渲染，避免测试依赖外部服务和额度。
- 浏览器模式不会显示 macOS 系统排期通知，只验证页面状态和后端状态更新。
- 真实 HyperFrames 集成测试需要本机具备 Node.js 22+、FFmpeg 和固定版本 CLI。
- Renderer 构建的 chunk 体积提示属于性能优化项，不是本次功能失败。
