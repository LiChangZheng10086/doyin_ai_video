# AI／科技资讯小版本

用户已授权实现、验证、编译重启并推送 origin/main；规格与计划由代理自行复核。

## 范围与设计

热点页新增「AI／科技资讯」页签，首批为 OpenAI、Google DeepMind、Microsoft Research 官方 RSS。保留原五个平台页签与解析逻辑。复用 HotspotService，每个 RSS 独立缓存、限频、故障与旧数据提示；不是混合热度榜。

RSS 仅请求固定 HTTPS 官方地址，禁止重定向，8 秒超时、响应最多 1 MiB。只接收同一官方域名原文、有效发布时间；HTML 摘要转纯文本，标题最多 500 字符、摘要最多 1000 字符。每源按发布时间倒序最多 100 条，去重 URL，用稳定 URL 作为条目 ID。列表序号只是顺序，资讯不保存热度。拒绝 DTD、非 RSS/Atom、空榜与越界字段。

资讯展示来源、原始发布时间和获取时间。收藏仍是来源+条目 ID 快照；下榜后仍可详情阅读、备注、创建公众号文章。详情复用 ResearchPanel 与安全正文读取，RSS 摘要明确仅供参考，不能作为已读原文或事实证据。详情读入公众号仍校验操作者、readId、hash；直接创作保留原文 URL 供读取。无法读取原文时沿用「需补充材料」，不冒充成功。

不部署 AIHOT、不使用其线上聚合 API，不增加凭据、付费服务、定时任务、翻译、事件聚类或新的发布动作。

## 验收

- 原五源解析、缓存与收藏回归不变；三个 RSS 独立故障、缓存重启与收藏完整链路通过。
- 桌面和窄屏页签、筛选、发布时间、收藏、详情和创作入口正常；无虚构热度。
- 真实官方 RSS 返回有效条目；至少一条经应用真实正文读取与隔离公众号导入验证。
- npm test、npm run check、npm run build；重启运行编译产物并核验 API。
- 明确提交到 origin/main，读回远程 SHA，同步 GitHub Issue。

已核对信任边界、历史收藏兼容、失败保留旧数据、五源隔离与原文证据要求；没有新增付费或平台发布范围。
