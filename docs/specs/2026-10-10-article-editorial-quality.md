# 公众号文章表达改善

用户已授权接入上一轮推荐的中文编辑方法，以现有 Skills 文章验证，编译重启并推送 origin/main。内部规格与计划复核由代理完成。

## 范围与实现

- 复用六步流程、ArticleWritingService 和 requirements 字段，不增加 Skills 执行器、服务或依赖。
- 选题诊断读取完整已纳入、可读来源，按资料消歧；三个方向按读者需求排序。未读摘要、排除来源不作为正文。
- 提纲、初稿、审校接入中文编辑规则：同一条主线、段落各有作用、具体读者问题、自然节奏、结尾回应开头；不强凑章节、排比或升华。
- 文风样本仅参考表达，优先于通用文风习惯；不得移植经历或事实。无样本不伪造作者身份。有实质功能的列表、术语和限定继续保留。
- 创建页高级设置开放已有 viewpoint、styleSample、length，自动与手动模式都传入要求。详情页已有这些字段，不增加第二套偏好系统。
- 审校保留原稿、修订稿与具体编辑说明，不用自评分充当质量门禁；JSON、事实引用、取消、最多三次重试与安全校验不变。

## 验收与发布

1. 先做失败回归：选题必须获得完整正确来源；排除来源与读取失败摘要不发送。
2. 验证创建页高级要求确实进入两种模式，既有隐私与恢复回归通过。
3. 备份现有 Skills 记录与稿件；使用相同输入、来源、写作要求与配置，通过原文章 API 重跑六步及预览，对照前后稿件。原输入和资料保留，不提交微信。
4. 检查技术事实、读者主线、开头/结尾、表达节奏。发现模型事实漂移时修正对应提示或补充既有资料，不以流畅掩盖问题。
5. 检查、测试、对应产物编译、单实例重启、origin/main SHA 读回、关联 Issue 验收同步。个人文章和对照全文仅保留本机。
