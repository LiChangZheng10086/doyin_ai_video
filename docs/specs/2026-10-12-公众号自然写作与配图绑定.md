# 公众号自然写作与配图绑定

用户选择自然、有具体细节、像作者认真讲一件事的写法；沿用图片提示词由用户在外部生图、上传绑定后文章直接使用的约定。内部规格与计划复核由代理完成。

## 实现范围

- 复用已有中文编辑规则，补充从事实摘录提取可观察细节、按内容组织段落；不编造作者经历、案例或数字。旧稿不自动改写。
- 自动文章生产默认不生成统一文字卡片，配图计划完成后缺图进入 needs_input/images_required，正文仍可预览。人工选图的已有恢复机制保留。
- 每个配图槽支持复制原提示词、上传并填写实际画面描述、复用具有同一提示词快照的素材。复用 AssetStore 的 generationPrompt 元数据，新增绑定操作校验文章版本、当前配图、素材种类与提示词快照。
- 封面直接成为当前封面，正文图按计划章节落位；替换保留旧素材，文章改稿不沿用旧提示词绑定。新计划与旧图仍走既有失效保护。
- 自动与手动工作台共用绑定面板。上传成功但绑定失败时显示已入库素材，允许选择后重新绑定，不自动重复上传。
- 不新增生图依赖、风格偏好系统，不修改已提交的微信草稿、不自动发布。

## 验收

隔离 API 验证缺图等待、上传快照与绑定、错配拒绝、旧版本冲突、替换与章节位置、资料修改失效；恢复不重跑已完成写作步骤。相关测试、类型检查与编译通过后报告；真实模型的文风和外部生图效果不能由模拟测试证明。

内部复核完成：配图与写作分别复用现有机制，授权范围明确，既有暂存改动保留，不影响其他平台成文。
