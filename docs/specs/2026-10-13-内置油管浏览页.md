# 内置油管浏览页

用户已批准内置浏览页、搜索浏览、前进后退与采集当前视频，并授权验证、编译重启、推送 origin/main。书面规格和计划由代理自行复核。

## 设计与范围

新增 `/youtube` 和「油管」主导航；移动端从「更多」进入，保持底栏六项。页头沿用现有样式，提供搜索／粘贴 YouTube 链接、前进、后退、首页、刷新与「采集当前视频」。下方显示 Electron WebContentsView 中的官方网站。纯浏览器环境明确提示需要桌面版。

油管使用独立持久化 partition，不加载应用 preload；nodeIntegration=false、contextIsolation=true、sandbox=true。主框架只准入 HTTPS 的 YouTube、短链和固定 Google 登录／同意域名，不放行其它顶层网址、凭据、端口或本地协议。新窗口在准入检查后合并到当前视图，否则拒绝。拒绝网页下载、摄像头、麦克风及通知权限。所有浏览 IPC 都校验本机应用窗口的主 frame 和实际 renderer 来源，外部页面与 iframe 不能调用。

React 占位区域把实际矩形交给主进程，主进程验证并限制在窗口内。离开页面、滚出可见区域或应用弹窗打开时隐藏网页并静音；返回保留浏览位置。窗口销毁关闭其 WebContents，重新加载应用也隐藏旧视图。

采集在点击时从主进程实际网址读取，仅允许包含 11 位视频 ID 的 watch／shorts／live／embed／短链，规范化为 `https://www.youtube.com/watch?v=ID`。加载中、失败页、搜索页与频道页拒绝采集。只通过现有 `apiClient.createJob` 创建手动作品并跳转详情，不自动转录、下载或发布。同步互斥防止重复点击，失败保留当前浏览位置。

首版不增加 API Key、YouTube Data API、频道批量采集、Cookie 导出或下载器登录态同步。内置浏览成功不保证下载成功。登录如受平台限制明确记录，不能宣称已验证真实账号登录。

## 验收

- 单元测试：网址／视频 ID、IPC 来源、导航、失败与加载状态、矩形、隐藏／销毁、防重复采集；既有作品与导航回归。
- 隔离真实 Electron：实际 WebContentsView、安全偏好、搜索与 SPA 网址更新、前进后退、隐藏、采集→现有 API→手动作业详情。合成网页通过测试专用网络响应提供，不放宽生产域名规则。
- 真实匿名 YouTube 浏览／搜索／视频页／播放按本机网络实测，失败不伪装成功；不登录真实账号或导出凭据。
- 检查、完整编译、重启当前桌面端，核验后端和新页；只提交任务文件，push origin/main 后同步 Issue，未验证的完成条件保持打开。

已自行复核来源隔离、页面生命周期与作品确认边界，复用现有下载／字幕／图集链路。
