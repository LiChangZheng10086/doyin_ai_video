## 实现的功能

### 1. API Key 验证工具

**文件：** `renderer/src/utils/apiKeyValidator.ts`

**功能：**
- `hasValidApiKey()` - 检查是否有活跃的 API Key
- `getActiveApiKey()` - 获取当前活跃的 API Key

**特点：**
- 异步检查，通过 Electron IPC 获取配置
- 错误处理：失败时返回 false 而不是抛出异常
- TypeScript 类型安全

---

### 2. 全局状态指示器

**文件：** `renderer/src/components/ApiKeyStatusIndicator.tsx`

**功能：**
- 显示三种状态：
  - ✅ **已配置**（绿点）
  - ⚠️ **未配置**（橙点 + "前往设置"链接）
  - 🔄 **检查中**（灰点 + 动画）

**集成位置：** 顶部导航栏右侧（`App.tsx`）

**触发检查时机：**
- 应用启动时
- 路由变化时（通过 `useLocation` 监听）
- 用户从设置页返回时

---

### 3. API Key 警告对话框

**文件：** `renderer/src/components/ApiKeyWarning.tsx`

**功能：**
- 未配置 API Key 时阻止任务创建
- 显示友好的警告信息
- 提供"前往设置"和"取消"按钮
- 点击"前往设置"自动导航到设置页

**触发位置：**
- 任务列表页的"创建任务"按钮
- 空状态的"立即创建"按钮

**用户体验：**
- 模态对话框，带半透明背景
- 明确的图标（⚠️）和说明
- 一键导航到设置页

---

### 4. 智能轮询服务

**文件：** `renderer/src/hooks/useJobPolling.ts`

**轮询策略：**

| 场景 | 间隔 | 说明 |
|------|------|------|
| 有任务处理中 | 3 秒 | status = 'queued' \|\| 'processing' |
| 所有任务完成 | 15 秒 | status = 'done' \|\| 'failed' |
| 没有任务 | 停止 | jobs.length === 0 |
| 离开页面 | 停止 | 组件卸载时清理定时器 |

**实现方式：**
- 自定义 React Hook
- 使用 `useEffect` + `setInterval`
- 依赖 `jobs` 状态动态调整间隔
- 自动清理定时器，防止内存泄漏

**UI 反馈：**
- 右下角显示"轮询中..."指示器（仅在有任务时）
- 绿色脉动动画
- 半透明背景，不遮挡内容
